# Date Intelligence Engine

A Python project that generates a structured profile from a given date.

## 🔍 Features
- Multi-calendar support (Gregorian, Islamic, Hindu)
- Zodiac sign with personality traits
- "On this day" historical facts

## 🛠️ Tech Stack
- Python
- datetime
- hijri-converter

## 📁 Project Structure
- main.py → core controller
- calendar_utils.py → Gregorian logic
- islamic.py → Hijri conversion
- hindu.py → Shaka calendar logic
- zodiac.py → personality traits
- history.py → historical events
- validators.py → input validation

## ▶️ How to Run
```bash
python main.py
